# 小臣版 AI-Boss 海投助手（增强筛选版）

基于 [Yangshengzhou 开源项目](https://gitee.com/Yangshengzhou/jobs_helper) 改进的 BOSS 直聘求职工具，专为**实习岗位**投递场景深度定制。

## 与原版的关系

本项目从 [小臣版 AI-Boss 海投助手（完整版）](https://github.com/DYxiaochen/AI-BossJob) 精简而来，是专为实习生打造的**瘦身增强筛选版**：

- **保留**：职位关键词筛选、AI 岗位匹配判断、简历上传与 AI 分析、批量沟通、多 AI 提供商支持
- **移除**：AI 聊天自动回复功能。本版仅负责自动打招呼，后续沟通对话以及简历发送**全权由求职者自行决策**，避免 AI 代聊带来的风险。同时移除图片简历发送、后端 API 依赖（`jasun.xyz`）、CryptoJS 依赖
- **新增**：实习薪资区间过滤、毕业年份/应届身份智能识别、更严格的 AI 岗位匹配策略

完整版仍在维护中，如果你需要 AI 自动聊天回复功能，请使用[完整版](https://github.com/DYxiaochen/AI-BossJob)。

## 功能特性

### 🔍 多维度职位筛选
- **职位名关键词**：包含关键词 + 排除关键词，支持逗号分隔多个
- **工作地过滤**：按城市/区域筛选
- **公司名排除**：自动跳过指定公司的岗位
- **实习薪资区间**：设置薪资上下限，自动识别日薪/月薪并统一换算比较。针对 BOSS 直聘网页版**无法按日薪筛选**的痛点设计，实习岗位常见日薪制，平台却只支持月薪过滤，本功能填补了这一缺口
- **排除猎头**：一键过滤猎头发布的岗位
- **招聘者活跃状态**：支持筛选"在线""刚刚活跃""今日活跃"等状态的 HR

### 🤖 AI 智能岗位匹配
- 支持上传 PDF/Word/TXT 简历文件，自动提取文本
- 支持直接粘贴简历内容
- AI 分析简历后，对每个岗位进行**严格匹配判断**，不编造经历、不泛化匹配
- 特别关注：毕业年份、应届届别、在校生身份、实习转正时间等实习关键要求
- 支持自定义 AI 角色提示词

### 🌐 多 AI 提供商
内置预设，一键切换，均使用 OpenAI 兼容 API：
- 讯飞星火
- 硅基流动（DeepSeek V2.5）
- 火山引擎（豆包）
- OpenAI（GPT-4o-mini）
- DeepSeek

也可填入任意兼容接口的自定义 API 地址和密钥。

### 📤 批量沟通
- 自动滚动加载职位列表
- 逐个打开职位详情并发起沟通
- 多城市自动切换投递
- 实时日志面板，投递进度一目了然

## 安装使用

### 环境要求
- 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
- 一个 AI API 密钥（上述任一提供商）

### 安装步骤
1. 在 Tampermonkey 管理面板中点击"新建脚本"
2. 将 `Boss_helper_enhanced.js` 全部内容粘贴进去
3. 保存脚本（Ctrl+S）
4. 打开 [BOSS 直聘职位搜索页](https://www.zhipin.com/web/geek/job)
5. 页面右侧会出现控制面板，点击 AI 配置按钮填入 API 密钥
6. 上传简历并点击"AI 分析简历"
7. 设置筛选条件后点击"启动海投"

### 推荐配置
- **AI 模型**：推荐 DeepSeek（`deepseek-chat`），性价比高
- **筛选策略**：建议开启 AI 岗位判断，开启排除猎头
- **实习薪资**：根据期望设置上下限，脚本会自动将日薪/月薪统一解析
